# 大乐透 + 排列三 + 快乐8 彩票预测

排列三、大乐透、快乐8 统一桌面预测工具。三个玩法**分区独立**：各自算法、各自历史数据、各自权重，互不影响。

已录入近100期中奖号码；快乐8 支持导入 `快乐8_近100期开奖数据.csv`。

> **声明**：本软件仅供学习、统计与算法研究。彩票开奖为随机事件，任何模型都无法保证中奖。请理性购彩，勿沉迷。

## 玩法说明

### 排列三（直选）

- 三位数字 `0–9`，**顺序必须完全一致**  
- 例：开奖 `1 2 4` → 1号位=1，2号位=2，3号位=3  

### 大乐透

- **前区**：01–35 任选 5 个（顺序无关）  
- **后区**：01–12 任选 2 个（顺序无关）  

### 快乐8

- 从 **01–80** 开出 **20** 个号码（顺序无关）  
- 本工具按走势图规则生成 **3 组选十**，并给出胆码 / 拖码建议（选五定胆、选七胆拖等缩水思路）

---

## 快乐8 规则说明

基于基本走势图（红圈开出 + 灰色遗漏）与空位结构，内置规则：

| 规则 | 思路 |
|------|------|
| 三空打中间 | 连续空出 3 个号码时，优先选中间位（如 15-17→16） |
| 四空打两边 | 空出 4 个时，取两端相邻号（如 30-33→29/34） |
| 六空打连子 | 空位 ≥6 时，布局内部连号对（如 50-57→51-52/55-56） |
| 封口斜连 | 上期末位邻号 + 斜向等差延伸（如 08-19-30→41/52） |
| 冷热搭配 | 短期高频号优先追踪，兼顾回补平衡 |
| 遗漏周期 | 遗漏 25–40 期分阶段轻仓补，避免重仓 |
| 连号必出 | 每期关注 1–2 组连号，中段 21–40 优先 |
| 四区对称 | 四区尾数互补 + 跨区对称号（如 12+68=80） |
| 跨度定胆 | 按上期跨度聚焦中段，对称号增效 |

三组选十侧重不同：

1. **A组·空位连号** — 三空 / 四空 / 六空 + 连号  
2. **B组·斜连对称** — 封口斜连 / 四区对称  
3. **C组·冷热跨度** — 冷热 / 遗漏周期 / 跨度定胆  

CSV 导入兼容桌面文件 `快乐8_近100期开奖数据.csv`（列：期号、开奖日期、号码1…号码20，或「期号 + 开奖号码」聚合列）。

## 算法说明（排列三 / 大乐透）

两端均为 **多算法加权集成（Ensemble）**：各位/号码层打分 → 组合成注 → 综合排序输出 TopN。  
开奖录入并「对比上次预测」后，按各算法在本期 Top10 上的表现 **EMA 修正权重**。

> 三套算法**互不共享权重与历史**，切换分区不会串数据。

## 运行方式

### 环境

- Windows 10/11  
- Python 3.10+（推荐 3.12）  
- 标准库 + `tkinter`  
- 大乐透 Excel 导入需要：`pip install openpyxl`  
- 打包需要：`pip install pyinstaller`

### 源码运行

```bash
cd lottery_suite
python app_gui.py
```

### 快乐8 数据

1. 将 `快乐8_近100期开奖数据.csv` 放到 `data/kl8/`，或在界面「录入 / 导入」中选择该文件  
2. 打开 **快乐8 → 基本走势图** 查看遗漏矩阵  
3. 在 **选十预测** 点击「生成3组选十」

命令行（可定点回测某一期，例如 2026188）：

```bash
python -m kl8.predict --csv data/kl8/快乐8_近100期开奖数据.csv --period 2026188 --export-trend --save
```

### 打包 exe

```bash
build_exe.bat
```

完成后：

- `dist/LotterySuite.exe` / `dist/彩票号码助手.exe`  
- 数据目录：`dist/data/pl3`、`dist/data/dlt`、`dist/data/kl8`

## 使用流程（简要）

1. 选择分区（排列三 / 大乐透 / 快乐8）  
2. **录入 / 导入**：录入或导入历史开奖  
3. **预测**：查看推荐注 / 3 组选十  
4. 下一期开奖后录入，点「对比上次预测」→ 自动修正权重  
5. 可随时「重置算法/规则权重」恢复默认
